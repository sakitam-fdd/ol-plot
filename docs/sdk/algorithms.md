# 算法与性能

OL Plot 的几何算法运行在地图坐标系中，输入是控制点，输出是 OpenLayers `LineString` 或 `Polygon`。

## 本轮优化

- 距离热路径新增平方距离比较，`pointermove` 不再每次执行开方。
- 贝塞尔曲线预计算二项式系数，每个采样点不再重复计算多次阶乘。
- 采样循环改为整数索引，稳定生成 `FITTING_COUNT + 1` 个点并精确保留首尾控制点。
- 三点共线的圆弧回退为折线，避免 `Infinity` / `NaN` 污染渲染管线。
- 零长度向量、平行线交点与反三角函数输入都增加数值保护。

## 复杂度

| 算法 | 时间复杂度 | 额外空间 |
| --- | --- | --- |
| 路径总长 | O(n) | O(1) |
| n 阶贝塞尔、s 个采样 | O(ns) | O(n + s) |
| 二次 B 样条 | O(ns) | O(s) |
| 箭头生成 | O(n + s) | O(n + s) |

`FITTING_COUNT` 默认是 100，兼顾交互平滑度和实时编辑成本。连续拖动时应更新既有 Geometry，不要反复创建 Feature。
