# Demo 与文档站规范

VitePress Playground 是首要产品示例，`playground/single` 是无框架参考实现，Vue 2/3 Playground 用于验证框架集成。

## 行为基线

交互式 Demo 至少覆盖一条完整工作流：

1. 选择点、线或面工具并开始绘制。
2. 完成或明确取消当前绘制。
3. 选择图形，激活和取消激活编辑。
4. 修改适用于当前几何的颜色、边框、透明度或大小。
5. 保存全部图形，清空后从快照恢复。

控件状态必须反映 SDK 状态：没有选中图形时禁用样式和编辑按钮；恢复场景后清除悬空选择；切换绘制工具时取消编辑状态。

## 样式模型

| 几何 | 必备控件 |
| --- | --- |
| 点 | 填充色、边框色、边框宽度、点大小 |
| 线 | 线颜色、线宽 |
| 面与箭头 | 填充色、填充透明度、边框色、边框宽度 |

示例应使用公开的 OpenLayers `Style`、`Fill`、`Stroke`、`Circle` API，并确保 `PlotUtils.getFeatures()` 能序列化生成的样式。样式状态可以作为普通 Feature 属性保存，但不要把不可序列化对象写入属性。

## UI 与可访问性

- 主要操作使用原生 `button`、`input` 与 `label`，提供可见焦点和禁用状态。
- 颜色控件同时显示可点击色块与文字标签；范围控件展示当前数值。
- 桌面端保持工具、样式和地图同时可见；窄屏允许面板折行或纵向排列，地图保留可操作高度。
- 切换或自动打开样式 Inspector 时不得调用 `updateSize()`、`fit()`、`setCenter()` 或 `setResolution()`；只有用户明确点击“缩放到”后才能改变地图中心或分辨率。窄屏工具区应保持固定高度，避免地图容器重排造成视觉缩放。
- 状态反馈使用页面内状态栏或 `aria-live`，不要依赖阻塞式弹窗。
- 深色和浅色 VitePress 主题下都需要可读。

## 实现与验收

- 文档组件位于 `docs/.vitepress/theme/components`，只在客户端创建 Map。
- 在 `onBeforeUnmount` 中依次释放 Plot、解除地图 target 和清理应用级监听。
- 独立 Demo 不复制 SDK 内部实现，只调用公开 API。
- 每次修改后构建 VitePress 与受影响的 Playground，并在真实浏览器中完成绘制、样式、保存恢复和窄屏检查。
